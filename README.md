# enteriors.in

The Enteriors website (PHP, for MilesWeb / LiteSpeed).

| Folder | What it is |
|---|---|
| `public_html/` | The website. This is the folder that goes on the server |
| `_removed-company/` | The retired firm sign-in, kept for reference only (not uploaded) |
| `docs/` | Notes: [upload steps](docs/upload-steps.md), [GA4 and Search Console setup](docs/ga4-setup.md), [UTM links](docs/utm-links.md), [SEO changes](docs/seo-changes.md), [keyword map](docs/keyword-map.csv) |

Start with [docs/upload-steps.md](docs/upload-steps.md).
